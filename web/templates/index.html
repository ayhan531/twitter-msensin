Render ücretsiz ve standart servislerinde disk geçicidir (ephemeral). Sunucu her deploy edildiğinde, yeniden başlatıldığında veya uyku modundan çıktığında yeni eklediğiniz hesaplar silinebilir.

🚀 Render'a Kaydetme Adımları (30 Saniye):

1. Render Dashboard'a gidin ve twitter-msensin servisini açın.

2. Sol menüden Environment sekmesine tıklayın.

3. Add Environment Variable butonuna basın: Key kısmına X_ACCOUNTS_DATA, Value kısmına yukarıdaki kodu yapıştırın.

4. Save Changes butonuna tıklayın. Bitti!
